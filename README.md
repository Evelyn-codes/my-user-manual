# 本人使用说明书

移动端优先的微信 H5 娱乐小测试。React + TypeScript + Vite，纯前端、本地计算，无登录、数据库或外部统计服务。

## 本地启动

建议 Node.js 22.12+；本次使用 Node.js 26。

```sh
npm ci
npm run dev
```

打开 http://localhost:5174/ 。`design/` 保存之前确认的视觉稿，5173 端口的旧页面不是正式测试。

## 构建与部署

```sh
npm test
npm run test:ui
npm run build
npm run preview
```

- `npm run build` 包含 TypeScript 检查，输出 `dist/`。
- 将 `dist/` 全部内容上传到任意静态托管服务；也可上传 `deploy.zip` 内的内容。
- 生产本地预览：http://localhost:4173/ 。
- 使用相对静态资源路径及 hash 页面导航，支持域名根目录和子目录部署，无需后端重写路由。
- 浏览器测试需要本机 Google Chrome。对构建产物运行：`TEST_URL=http://localhost:4173/ npm run test:ui`。

部署前在构建环境配置，或将 `.env.example` 复制为 `.env.local`：

```ini
VITE_SITE_URL=https://your-domain.example/
```

如部署在子目录：`VITE_SITE_URL=https://your-domain.example/manual/`。配置的是首页完整地址，不带来源参数或 hash。二维码与复制链接共用该配置；未设置时使用当前页面的域名与路径。更换部署地址后需要重新构建。开发环境生成的 localhost 二维码不适合发给朋友，请使用正式地址构建后再分享。

## 进度保存规则

- 每次选答案、前进、返回上一题立即同步写入 localStorage，不依赖退出事件或延迟定时器。
- 保存 18 个答案、当前题号、完成状态、内容结构版本以及当前轮次和修订号。
- 做到第六题，关闭页面再打开仍回到第六题；第六题已选择但尚未下一题时，也会恢复该选择。
- 回首页再退出仍保留最后题号，重新进入回到该题。
- 提交最后一题时先保存完成状态，再显示约 1.1 秒的过渡；即使在过渡期间退出，再打开也直接显示结果。
- 已完成后返回站点直接显示自己的结果。浏览图鉴或打开带朋友结果参数的链接不会覆盖自己的答案或结果。
- 重新测试可取消；确认后原子覆盖为最新一轮的空答案与第一题，不保留旧一轮的有效进度。
- 同一站点的多个页面通过 storage/pageshow/visibilitychange 同步；旧历史页面和旧轮次不会将已重开的测试覆盖回去。
- 存储损坏、不可用或配额不足会明确提示；存储失败时允许继续本轮，不假装保存成功。
- 数据只属于同一浏览器、同一站点来源（协议/域名/端口）。清理浏览器数据、切换浏览器、设备或站点来源不会迁移进度。

## 评分与内容

- 以 `本人使用说明书 V2.md` 为唯一内容源，18 道题固定顺序，每个维度各 6 题，每题只有一个维度允许非零分。
- `A>=2` 为 A3，`A<=-2` 为 A1，中间为 A2；`B>=2` 为 B1，`B<=-2` 为 B3，中间为 B2。
- `C>0` 为 C1，`C<0` 为 C2；`C=0` 使用 Q18：A/B → C1，C/D → C2。Q18 正常计入 C 总分。
- 数据条统一 `Math.max(0, Math.min(100, Math.round((score+6)/12*100)))`。
- 结果卡全部采用 V2 文案，系统状态后追加给自己的 Tips；LOADING 按新文档命名为“缓冲中”。
- 新进度使用 `my-user-manual:progress:v2`；旧 v1 记录保留但不套入新题库，不自动改写旧结果统计。旧用户需重新测试，设备安装标识不变。
- 图鉴只呈现静态人格内容，没有用户数据条，不能替换本轮结果。

## 分享海报

使用本地 Canvas 和本地二维码库，生成真实 PNG，宽度 1080px、高度按完整文案自适应且不少于 1440px。包含标题、人格名/代码、OS、正确角色、完整结果描述、两条好友使用说明和二维码。

按用户后续确认的设计，V2 海报显示三维标签和系统状态，不显示数据条或给自己的 Tips；结果页仍显示真实数据条。文字不删减，只合并描述换行。二维码 300×300px，包含四模块留白，使用 `from=poster` 和实际结果键。

完成后以真正的图片展示，提示“长按图片保存，再发给朋友。”；非微信环境另提供下载链接。图片生成失败可重试。生成器动态加载，首页不加载二维码生成模块。

微信没有接入 JSSDK 或公众号签名服务，因此没有自定义微信右上角分享卡片，也没有一键分享到朋友圈。微信 UA 下已验证图片预览和按钮策略；真实微信长按保存与扫一扫仍需正式 HTTPS 地址上的手机实测。

## 隐私与事件

`src/lib/tracking.ts` 提供 `track(eventName,payload)`，默认只在开发环境输出日志，生产环境不发送任何统计网络请求。

已接入 `landing_view`、`test_start`、`question_answered`、`test_completed`、`result_viewed`、`poster_generated`、`result_link_copied`、`restart_clicked`。载荷白名单仅允许题号与结果键，不包含原始答案、轮次标识、昵称、手机号或微信身份。未来接入外部统计需单独配置。

## 主要文件

- `src/App.tsx`：流程、进度恢复、导航、多页面同步与交互。
- `src/components/Manual.tsx`：图标、名称、数据条、好友说明与弹层。
- `src/lib/scoring.ts`：独立纯函数评分。
- `src/lib/progress.ts`：持久化数据模型、校验、读写和异常处理。
- `src/lib/poster.ts`：高清 PNG 与二维码。
- `src/lib/links.ts`：环境变量与分享链接构建。
- `src/lib/tracking.ts`：事件白名单及开发日志适配。
- `src/data/questions.ts`、`results.ts`、`images.ts`、`site.ts`：独立内容和素材映射。
- `src/data/demoFixtures.ts`：仅测试使用的固定答案样本，不接入正式页面或评分。
- `public/characters/`：压缩后的本地图片副本；18 张共约 4.2MB，按当前页面需求加载。
- `tests/`：内容、评分、持久化与真实浏览器验收。
- `test-results/`：自动化截图、18 张导出 PNG 及检查记录（不进入 dist）。
